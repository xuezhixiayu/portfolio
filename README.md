# 郑佳辉 · 个人作品集

包含三套可切换的作品集风格、独立简历和本地内容管理页面。作品、经历和关于在同一页面浏览，作品详情通过弹窗打开。

- 帧之间：悬浮画面和镜头视差。
- 异世界入口：整屏作品场景、拖动裂缝切换。
- 会动的漫画：漫画分格和动态作品展示。
- 共 14 部作品，包含从 yywf.top/works 去重补充的 8 部。
- 可分别设置三套风格的首页作品、作品顺序、标题、字体、颜色和动效。

## 本地运行

需要 Node.js。在项目目录执行：

```sh
node server.cjs
```

然后打开 `http://127.0.0.1:4173/`。Windows 也可双击 `start-preview.cmd`。

| 入口 | 路径 |
| --- | --- |
| 作品集 | `studio/index.html` |
| 个人简历 | `studio/resume.html` |
| 后台管理 | `studio/admin.html` |
| 导出页面 | `studio/export.html` |

使用 `?theme=frames`、`?theme=portal` 或 `?theme=comic` 可直接预览指定风格。

## 内容管理

首次本地管理密码为 `admin123`。作品信息和个性化设置保存在当前浏览器的 IndexedDB 中；同一浏览器、同一站点下三套风格共用内容。

浏览器里已保存的个人修改不会自动上传到 GitHub，也不会同步给其他访客。需要保存这些修改时，在后台导出 JSON 备份；独立 HTML 导出可生成当前内容的只读首页快照。

此项目是静态站点，本地后台密码用于本机编辑界面，不是服务器权限验证。

## 文件结构

```text
studio/       当前作品集、简历、后台与导出页面
shared/       共用样式、脚本、作品数据及媒体
cinema/       沉浸影院版
gallery/      数字创作展厅版
server.cjs    本地预览服务
```
